## 尚需人工验收

在专用测试会话中验证以下流程，不能用连接检查或 mock 测试替代：

1. 手机端新建工作树，选择项目、模型与思考强度。
2. Slack 频道发送真实用户消息，验证模型执行、回复及去重。
3. 看终端、回答按键、中断、`/clear`、暂停/恢复同步。
4. 图片和文件实际投递到模型。
5. 运行中断网并恢复、服务重启后消息不重复执行。
